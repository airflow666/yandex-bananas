# 🍌 Банановая башня (Banana Tower)

Казуальная HTML5-игра для платформы [Яндекс Игры](https://yandex.ru/games) на Phaser 3.

Строй башню из связок бананов: блок качается над башней — тапни в нужный момент,
чтобы сбросить его. Промахнулся краем — свес отрежется и башня станет уже.
Полный промах — конец игры. Чем выше башня, тем быстрее качается блок.

## Возможности

- **Геймплей**: маятниковый Tower Builder с «идеальными» попаданиями, комбо и ростом сложности; фон меняется с высотой (джунгли → небо → космос)
- **Монетизация (Yandex Adv API)**:
  - interstitial — при рестарте/выходе в меню, с кулдауном 60+ секунд
  - rewarded — «вторая жизнь» после промаха, x2 бананов на экране результатов, x2 ежедневного бонуса, бесплатный скин
  - sticky-баннер — в меню и на game over (скрывается в геймплее)
- **Лидерборд** Яндекса (`towerScore`) + экран топ-игроков
- **Облачные сохранения** (`player.setData`) с fallback на localStorage
- **Магазин скинов** за внутриигровую валюту (бананы) и за рекламу
- **Ежедневный бонус** со стриком
- **Локализация** RU/EN (по языку из SDK)
- **Звуки** генерируются WebAudio — внешних ассетов нет вообще, вся графика рисуется кодом
- Обязательные для модерации вызовы: `LoadingAPI.ready()`, `GameplayAPI.start()/stop()`
- **Mock-режим SDK**: вне Яндекса игра полностью играбельна, реклама и лидерборд эмулируются (лог в консоли `[YSDK-mock]`)

## Разработка

```bash
npm install
npm run dev      # http://localhost:5173 — mock-режим SDK
npm run build    # продакшн-сборка в dist/
```

## Публикация в Яндекс Играх

1. **Сборка и архив** (Linux/macOS)

   ```bash
   npm run build
   cd dist && zip -r ../banana-tower.zip . && cd ..
   ```

   Важно: в архиве `index.html` должен лежать в корне (так и получается при команде выше).

   ### Сборка и архив на Windows

   1. Установи [Node.js LTS](https://nodejs.org/) (в установщике оставь галочку
      «Add to PATH»). Проверь установку — открой **PowerShell** и выполни:

      ```powershell
      node -v
      npm -v
      ```

      Обе команды должны напечатать версии (Node 18 или новее).

   2. Получи код проекта: `git clone <url-репозитория>` (если установлен
      [Git для Windows](https://git-scm.com/download/win)) или скачай ZIP репозитория
      с GitHub («Code» → «Download ZIP») и распакуй. Перейди в папку проекта:

      ```powershell
      cd C:\путь\до\yandex-bananas
      ```

   3. Установи зависимости и собери игру:

      ```powershell
      npm install
      npm run build
      ```

      Готовая сборка появится в папке `dist\`.

   4. Создай архив для загрузки в Яндекс:

      ```powershell
      Compress-Archive -Path dist\* -DestinationPath banana-tower.zip -Force
      ```

      ⚠️ Именно `dist\*` (содержимое папки), а не `dist` — иначе `index.html`
      окажется внутри вложенной папки, а не в корне архива, и Яндекс такую
      сборку не примет.

      Без консоли: открой папку `dist` в Проводнике, выдели **все файлы внутри неё**
      (Ctrl+A), правый клик → «Сжать в ZIP-файл». Архивировать нужно файлы,
      а не саму папку `dist`.

   5. Проверить игру локально на Windows можно той же командой `npm run dev` —
      игра откроется на `http://localhost:5173` в mock-режиме SDK.

   Дальнейшие шаги (консоль разработчика, лидерборд, карточка, песочница) —
   одинаковы для всех платформ, см. пункты ниже.

2. **Консоль разработчика**: зайди на [Яндекс Игры для разработчиков](https://games.yandex.ru/console/), создай приложение-черновик, загрузи `banana-tower.zip`.

   Материалы для карточки игры (иконка 512×512, обложка, 5 скриншотов, готовые тексты
   названия/описаний RU+EN, рекомендации по категории и возрастному рейтингу) лежат в
   папке [`store/`](store/CARD.md).

3. **Лидерборд**: в консоли открой раздел «Лидерборды» и создай лидерборд с техническим именем **`towerScore`** (тип — «числовой», сортировка — по убыванию). Имя должно совпадать с константой `LEADERBOARD_NAME` в `src/yandex/sdk.js`.

4. **Реклама**: монетизация включается в консоли (раздел «Реклама»). Показ идёт через Рекламную сеть Яндекса (РСЯ) — для вывода денег понадобится заключить оферту в кабинете РСЯ. Отдельных ad unit id в коде не нужно: SDK сам решает, что показывать.

5. **Проверка в песочнице**: черновик доступен по ссылке вида `https://yandex.ru/games/app/<ID>/?draft=true` — там работает настоящий SDK (реклама, лидерборды, сохранения).

6. **Чек-лист модерации** (уже учтено в коде, но проверь после изменений):
   - игра вызывает `LoadingAPI.ready()` после загрузки — есть, в сцене Menu, ровно один раз;
   - `GameplayAPI.start()/stop()` при старте/паузе геймплея — есть: старт/стоп в сцене Game, стоп при показе рекламы и сворачивании вкладки;
   - звук выключается во время рекламы и при сворачивании вкладки — есть;
   - кнопка выключения звука доступна и в меню, и во время геймплея — есть;
   - нет запросов к внешним доменам (все ресурсы в сборке) — есть, проверено автотестом;
   - interstitial не чаще раза в минуту и только в «естественных паузах» — есть (`src/systems/ads.js`);
   - награда за rewarded выдаётся только после события `onRewarded`; при закрытии ролика раньше времени награды нет — есть;
   - игра не требует авторизации и не запрашивает персональные данные (`getPlayer({ scopes: false })`) — есть;
   - лидерборд не падает у неавторизованных: топ показывается, для участия — подсказка войти в Яндекс;
   - все SDK-вызовы обёрнуты в try/catch — отказ рекламы/лидерборда/сохранений не ломает игру;
   - есть локализация RU (обязательна) — есть: русский для всего русскоязычного каталога
     (`ru`, `be`, `kk`, `uk`, `uz`), английский для остальных; склонения числительных учтены;
   - корректный ресайз окна — Phaser Scale.FIT.

## Структура кода

```
index.html                  подключение /sdk.js Яндекса + контейнер игры
src/main.js                 конфиг Phaser, сцены
src/yandex/sdk.js           обёртка Yandex Games SDK + mock для локальной разработки
src/systems/ads.js          показ рекламы: кулдаун interstitial, rewarded, глушение звука
src/systems/saves.js        монеты/рекорд/скины/ежедневный бонус, облако + localStorage
src/systems/i18n.js         словари RU/EN
src/systems/audio.js        звуки на WebAudio (без файлов)
src/skins.js                описания скинов
src/ui.js                   кнопки, счётчики, тосты
src/scenes/Boot.js          инициализация SDK и сохранений
src/scenes/Menu.js          меню, ежедневный бонус, LoadingAPI.ready()
src/scenes/Game.js          основной геймплей + оффер «второй жизни»
src/scenes/GameOver.js      результаты, x2 за рекламу, interstitial на рестарт
src/scenes/Shop.js          магазин скинов
src/scenes/Leaderboard.js   топ игроков
```

## Как это монетизируется

| Показ | Формат | Триггер |
|---|---|---|
| Вторая жизнь | rewarded | промах при башне от 3 этажей, раз за забег |
| x2 бананов | rewarded | экран результатов, если заработано > 0 |
| x2 ежедневного бонуса | rewarded | попап бонуса в меню |
| Бесплатный скин | rewarded | карточка «Радужный» в магазине |
| Между забегами | interstitial | кнопки «Заново»/«Меню», кулдаун 62 сек |
| Фоновый | sticky-баннер | меню и экран результатов |
